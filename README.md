# Be The Bear

カメラの前で体を動かして、スキーをするクマと一緒に1,500mの雪山を滑るブラウザーゲームです。コインを集め、ジャンプ台では空中のお金の袋を狙いましょう。

**[Be The Bear を遊ぶ](https://be-the-bear.kait0.workers.dev/)**

![雪山のコースを滑るクマと、前方に並ぶコイン。プレイ中は画面上部にタイムとスコアが表示されます。](docs/be-the-bear-slidev/public/images/demo-game.png)

## 遊び方

タイトル画面からロビーに進み、**PLAY** で操作方法を選びます。身体操作では、カメラに正面を向き、頭から足先まで映してスキャンを完了させます。キーボードでもプレイできます。

![身体操作の対応図。左右に重心を移すとクマが同じ方向に移動し、その場で跳ぶとジャンプ。しゃがんで前傾姿勢を保つと加速します。](docs/images/body-controls.png)

| クマの動き | 身体操作 | キーボード |
| --- | --- | --- |
| 左右に移動 | 重心を行きたい方向へ移す。体を中央に戻すと、その横位置で止まる | ← / → または A / D |
| ジャンプ | その場で跳ぶ | Space または ↑ |
| 加速 | しゃがんで前傾姿勢を保つ | ↓ または S を押し続ける |
| 一時停止 | 画面の一時停止ボタンを押す | Esc |

タッチボタンでも左右移動・ジャンプ・加速ができます。集めたコインはロビーの **SHOP** でマフラーと交換できます。
