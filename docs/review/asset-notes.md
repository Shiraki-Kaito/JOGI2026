# 固定背景素材

`web/public/assets/cloud-panorama.webp` は組み込みの画像生成ツールで生成した固定背景。承認されたA案の完成イメージを参照し、熊・スキー・雪煙・文字を除いたPNGをWebPへ変換した。

指示：横長16:9、ローポリ9：自然な光1。左寄りの主峰、重なる雪山、青空、白い雲海。雪をかぶった非対称の谷と右の尾根、左の岩の肩、まばらな針葉樹を含む。下部は3Dの雪面を重ねるための明るい雪。大きな灰色のピラミッド形状や写実的な素材を避ける。

背景内の地形は固定画像。手前の滑走面、岩、木、報酬、ジャンプ台、熊は3D。遠い装飾雪面を透過して背景へなじませる。

確認画像はゲームのCanvas描画コードで生成したもの。HTMLのUIを含まず、ブラウザーのスクリーンショットではない。WebGLでの表示は実機確認が必要。
