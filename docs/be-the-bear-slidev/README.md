# Be The Bear 発表資料

チーム：しゃりしゃり。本編12枚。白・ネイビー・シアンを基調としたSlidev資料です。

## 起動・ビルド

```bash
npm ci
npm run dev
```

ビルドは `npm run build`。生成物は `dist/` に出力されます（Git管理対象外）。動画・画像・フォントは資料内のファイルを使用します。

## 本番は録画を再生

4枚目で `public/videos/be-the-bear-playtest.webm` を再生し、対応しないブラウザーでは同名の `.mp4` を使用します。添付された「test動画.mp4」の全編、約58.97秒です。映像の外側の黒帯のみを除き、ブラウザー向けのWebM（VP9/Opus）とMP4（H.264/AAC）に再エンコードしています。速度変更・場面の切り貼り・音声削除はしていません。

4枚目では動画の先頭画面を表示して停止します。再生ボタンを押すと開始します。自動再生はしません。再生音量は会場で確認してください。次のスライドへ移ると停止し、戻ると先頭へ戻ります。PDFはポスター画像による静止プレビューで、動画を再生できません。

本番でのカメラ実演は行いません。動画には操作している本人とゲーム画面が収録されています。画面に見えていない動作を、録画中に行ったと説明しないでください。

再生できない場合は、4枚目に表示するポスター画像で操作を説明し、5枚目へ進みます。

## 発表原稿

発表者ノートは `slides.md` のコメント、同じ原稿を `発表原稿.md` に収録。12枚目のQRコードを表示したまま発表を終えます。

## 素材と検証の範囲

表紙・7枚目のスキャン図は正式採用した説明図であり、実カメラ映像ではありません。4枚目の動画には実際のプレイ映像とカメラ映像が含まれます。その他のゲーム画像は提供素材を使用しています。ポスター画像は動画から切り出しています。

ジャンプは肩と腰の上昇速度・動きの一致を軸に足の情報も使用し、足の検出をすべての経路で必須にはしません。認識は同時に1枚で、画像取得から250ms超の結果は破棄します。250msは採用上限で、実測した操作遅延ではありません。

関連テスト35件成功は2026-10-15の既存記録。body-control 15件、auto-calibration 6件、pose-camera 14件。合成入力・モックの確認であり、保存処理や実機での認識精度の評価は含みません。録画を、定量的な精度評価や遅延測定の結果として扱わないでください。

## 評価観点

- 技術の相当性：5枚目の役割と採用理由。
- アーキテクチャ・設計：6枚目の実行場所、責務、データの流れ、保存への接続。
- 技術的な挑戦：7〜9枚目の個人差、ジャンプ判定、処理待ち対策。
- 完成度：4枚目の録画、10枚目の中断復帰・記録保存・着せ替え。
- 技術的な面白さ：骨格座標をゲーム操作へ変える工夫。
